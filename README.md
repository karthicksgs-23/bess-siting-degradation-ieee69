# Degradation-aware BESS siting and sizing on the IEEE 69-bus feeder

A mixed-integer linear program places and sizes battery storage on the IEEE 69-bus distribution feeder. It compares three battery-wear models in the planning stage:

- **M0:** no cycle wear.
- **M1:** a throughput price.
- **M2:** a segmented cycle-depth price.

Each plan is then audited with rainflow counting and an exact AC power flow.

## Files
| File | Purpose |
|---|---|
| `net69.py` | IEEE 69-bus data (MATPOWER `case69.m`) and backward/forward-sweep AC power flow (check: 224.99 kW losses, 0.9092 pu at bus 65) |
| `inputs.py` | Three representative days: PVGIS-ERA5 PV (Hyderabad 2020), seasonal load shapes, time-of-day and market-scenario prices |
| `model.py` | MILP: LinDistFlow with BFS correction, tangent loss cuts, modular BESS, wear models M0/M1/M2; solved with HiGHS via SciPy |
| `audit.py` | Rainflow wear audit and AC power-flow check of a plan |
| `run_study.py` | Experiments: `base`, `sens <kp>`, `capex`, `fullcand` |
| `repair_m2.py` | M2 re-solve on a reduced candidate set for the ₹9k and ₹7k cell-cost cases |
| `analyze.py` | Polishing of time-limited M2 plans, proxy error and regret → `results/analysis.json` |
| `fig_static.py`, `fig_results.py` | Figures (written to `figures/`) |
| `data/` | `case69.m` (MATPOWER) and the PVGIS hourly PV series |
| `results/` | Result JSON files and run logs; dispatch `.pkl` files are regenerated by the runs |

## Reproduce
```
pip install -r requirements.txt
python net69.py                  # power-flow validation
python run_study.py base
python run_study.py sens 1.2 ; python run_study.py sens 1.8 ; python run_study.py sens 2.4
python run_study.py capex ; python repair_m2.py 9 ; python repair_m2.py 7
python run_study.py fullcand
python analyze.py
python fig_static.py ; python fig_results.py inputs base capex
```

## Data sources
- Feeder: MATPOWER `case69.m` (Baran and Wu 69-bus system), distributed under the MATPOWER BSD licence.
- PV: PVGIS-ERA5 hourly data from the European Commission JRC PVGIS web service.
